*Brasil em Números
-Um projeto que estou desenvolvendo para aprender Python e explorar dados sobre os estados brasileiros.

*Sobre o projeto
-A ideia do O Brasil em Números é mostrar informações sobre a população dos estados brasileiros de um jeito simples e fácil de entender.
Criei esse projeto como parte dos meus estudos em programação. Durante o desenvolvimento, fui aprendendo a buscar dados na internet, 
organizar essas informações e apresentá-las em uma página interativa.

*O que o projeto faz?
- Mostra os estados brasileiros, suas siglas e regiões.
- Permite escolher um estado para consultar seus dados.
- Exibe informações sobre a população.
- Mostra um gráfico com a evolução da população ao longo dos anos disponíveis.
- Organiza os resultados em tabelas para facilitar a consulta.

*Tecnologias que usei
-Python: a linguagem que usei para desenvolver o projeto.
-Streamlit: para criar a página interativa.
-Pandas: para organizar os dados em tabelas.
-Altair: para criar o gráfico.
-API do IBGE: para buscar as informações sobre os estados e a população.

*Fonte dos dados: As informações são consultadas nas APIs disponibilizadas pelo IBGE.
- [API de Localidades](https://servicodados.ibge.gov.br/api/v1/localidades/estados)
- [API de dados agregados](https://servicodados.ibge.gov.br/api/v3/agregados)

*Aprendizado e desenvolvimento
-Este projeto foi desenvolvido como parte da minha jornada de aprendizado em Python. 
Durante o desenvolvimento, utilizei ferramentas de inteligência artificial como apoio para estudar conceitos, compreender erros, explorar soluções e aprimorar a organização do código.
O processo me permitiu praticar o consumo de APIs, a manipulação de dados, a criação de gráficos e o desenvolvimento de aplicações com Streamlit.
Mais do que concluir uma aplicação, meu objetivo foi aprender com cada etapa, entender os problemas encontrados e evoluir minhas habilidades de programação.
